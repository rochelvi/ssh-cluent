# Cluent

Полностью офлайн SSH-клиент для Windows: Tauri 2 + Rust ([russh](https://crates.io/crates/russh)) + xterm.js.

## Возможности

- **Хосты** с группами и поиском, вход по паролю (в т.ч. keyboard-interactive) или по приватному ключу. Хост можно **дублировать**: копия создаётся с тем же названием и сохранённым паролем, переименовываете её сами.
- **Импорт из `~/.ssh/config`** (или любого другого файла): переносятся `HostName`, `Port`, `User`, `IdentityFile`, `LocalForward`/`RemoteForward`/`DynamicForward`, поддерживаются `Host *`, шаблоны и `Include`. Хосты, которые уже есть, по умолчанию не отмечены.
- **Терминал** во вкладках (xterm-256color). Сочетания копирования и вставки переназначаются в настройках (по умолчанию `Ctrl+C` / `Ctrl+V`). Если копирование назначено на `Ctrl+C`, оно срабатывает только при выделенном тексте, а без выделения `Ctrl+C`, как обычно, прерывает процесс.
- **Копирование при выделении** и вставка правой кнопкой мыши включаются переключателем в настройках.
- **Пользователь по умолчанию** задаётся в настройках и подставляется в новые хосты и при импорте, если в конфиге нет `User`.
- **SFTP**: просмотр каталогов, загрузка и скачивание (в том числе перетаскиванием из Проводника), создание папок, переименование и удаление. При конфликте имён передача сохраняет уже существующий файл.
- **Проброс портов**: локальный (`-L`), удалённый (`-R`) и динамический SOCKS5 (`-D`). Правила задаются в настройках хоста и включаются при подключении.
- **Проверка ключа хоста** (TOFU): отпечаток SHA256 показывается при первом подключении, а при смене ключа появляется предупреждение.

## Приватность

- Никакой телеметрии, аналитики, crash-репортеров и автообновлений. Сеть используется только для SSH-подключений, которые вы запускаете сами.
- Хосты хранятся в `%APPDATA%\app.cluent.desktop\hosts.json`, настройки — в `settings.json`, ключи хостов — в `known_hosts` в той же папке.
- Пароли и парольные фразы **не сохраняются**: они запрашиваются при каждом подключении и хранятся только в памяти. Пароли, сохранённые прежними версиями в Диспетчере учётных данных Windows, удаляются при запуске.
- Строгий CSP: интерфейс не может обращаться к внешним адресам. Шрифты и ресурсы не загружаются из интернета.

## Безопасность

- **Ключи хостов.** Неизвестный хост подтверждается по отпечатку SHA256. Если ключ сменился, в том числе на ключ другого типа для уже известного хоста, показывается предупреждение о возможной атаке MITM.
- **Каналы от сервера.** Каналы, которые сервер открывает сам (agent forwarding, X11, session и т.п.), отклоняются. Принимаются только туннели `-R`, которые настроили вы.
- **Вставка в терминал.** Текст с переводом строки вставляется только после подтверждения с предпросмотром, если удалённая сторона не включила bracketed paste. Управляющие символы из буфера обмена вырезаются.
- **SFTP.** Имена файлов с сервера не могут увести скачивание за пределы выбранной папки: `..`, `\`, `:` и имена устройств Windows обезвреживаются в интерфейсе и дополнительно проверяются в бэкенде.
- **Пароли.** keyboard-interactive отправляет пароль только в скрытые поля ввода, не в видимые (например, «Verification code»).
- **Одна копия.** Одновременно может работать только одна копия приложения, поэтому данные не перезаписываются из двух процессов.
- **Алгоритмы.** Список алгоритмов задан явно в `ssh.rs` (`preferred_algorithms`) и проверяется тестом: без SHA-1 (ни MAC, ни подписи ключа хоста `ssh-rsa`), без CBC, со strict-kex (защита от Terrapin) и пост-квантовым `mlkem768x25519-sha256`.
- **Проверка зависимостей.** `cargo audit` и `npm audit` запускаются в GitHub Actions раз в месяц и при каждом изменении lock-файлов. Автообновления нет, поэтому следите за страницей релизов; текущая версия показана рядом с логотипом.
- **Сборка.** Релиз собирается с Control Flow Guard, без путей сборки и имени пользователя в exe. WebView2 запускается с включённым SmartScreen.

## Разработка

Нужны Node.js 20+, Rust (stable, MSVC) и Visual Studio Build Tools (C++).

```powershell
npm install
npm run tauri dev
```

Релизная сборка (установщик NSIS, портативный exe и `SHA256SUMS.txt` в папке `portable/`):

```powershell
npm run release
```

Установщик не скачивает WebView2: в Windows 10/11 он уже встроен.

Сборки пока не подписаны цифровой подписью. Сверяйте SHA-256 скачанного файла с опубликованным в релизе:

```powershell
Get-FileHash .\Cluent-<версия>-portable.exe -Algorithm SHA256
```

## Структура

- `src-tauri/src/ssh.rs` — подключение, аутентификация, shell и SFTP-сессия.
- `src-tauri/src/forward.rs` — проброс портов `-L` и SOCKS5.
- `src-tauri/src/sftp.rs` — файловые операции.
- `src-tauri/src/store.rs` — хранилище хостов.
- `src-tauri/src/known_hosts.rs` — ключи хостов.
- `src-tauri/src/settings.rs` — настройки приложения.
- `src-tauri/src/ssh_config.rs` — разбор `~/.ssh/config` для импорта.
- `src/` — интерфейс на TypeScript (без фреймворков).
