# Cluent

Полностью офлайн SSH-клиент для Windows: Tauri 2 + Rust ([russh](https://crates.io/crates/russh)) + xterm.js.

## Возможности

- **Хосты** с группами и поиском, вход по паролю (в т.ч. keyboard-interactive) или по приватному ключу.
- **Терминал** во вкладках (xterm-256color), копирование и вставка как в Windows Terminal: `Ctrl+C` копирует выделенный текст (без выделения отправляет ^C), `Ctrl+V` вставляет. Также работают `Ctrl+Shift+C`/`Ctrl+Shift+V` и правая кнопка мыши, как в PuTTY.
- **SFTP**: просмотр каталогов, загрузка и скачивание (в том числе перетаскиванием из Проводника), создание папок, переименование и удаление.
- **Проброс портов**: локальный (`-L`), удалённый (`-R`) и динамический SOCKS5 (`-D`). Правила задаются в настройках хоста и включаются при подключении.
- **Проверка ключа хоста** (TOFU): отпечаток SHA256 показывается при первом подключении, а при смене ключа появляется предупреждение.

## Приватность

- Никакой телеметрии, аналитики, crash-репортеров и автообновлений. Сеть используется только для SSH-подключений, которые вы запускаете сами.
- Хосты хранятся в `%APPDATA%\app.cluent.desktop\hosts.json`, ключи хостов — в `known_hosts` в той же папке.
- Пароли и парольные фразы хранятся в **Диспетчере учётных данных Windows** (DPAPI), а не в файлах приложения.
- Строгий CSP: интерфейс не может обращаться к внешним адресам. Шрифты и ресурсы не загружаются из интернета.

## Разработка

Нужны Node.js 20+, Rust (stable, MSVC) и Visual Studio Build Tools (C++).

```powershell
npm install
npm run tauri dev
```

Сборка установщика (NSIS):

```powershell
npm run tauri build
```

Установщик не скачивает WebView2: в Windows 10/11 он уже встроен.

## Структура

- `src-tauri/src/ssh.rs` — подключение, аутентификация, shell и SFTP-сессия.
- `src-tauri/src/forward.rs` — проброс портов `-L` и SOCKS5.
- `src-tauri/src/sftp.rs` — файловые операции.
- `src-tauri/src/store.rs` — хранилище хостов и секретов.
- `src-tauri/src/known_hosts.rs` — ключи хостов.
- `src/` — интерфейс на TypeScript (без фреймворков).
